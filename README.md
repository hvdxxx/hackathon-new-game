# Godot Game Project

Проект игры, разработанный на движке **Godot Engine**.

## 📋 Описание

Это 2D-игра, включающая:
- Главного героя с системой управления
- Босс-файт с UI интерфейсом
- Систему диалогов
- Врагов (Enemy One, Dog Husky, Dog Two)
- Интерактивные объекты (замки, зоны атаки)
- Интро-последовательность и главное меню

## 🚀 Требования

- **Godot Engine** версии 4.x (или версии указанной в `project.godot`)

## 🛠️ Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <url-репозитория>
   cd <папка-проекта>
   ```

2. Откройте проект в Godot Engine:
   - Запустите Godot
   - Нажмите "Import"
   - Выберите файл `project.godot`

3. Запустите игру через редактор Godot (F5)

## 📁 Структура проекта

```
├── MainHero.tscn          # Сцена главного героя
├── MainMenu.tscn          # Главное меню
├── BossUI.tscn            # UI босса
├── IntroScreen.tscn       # Интро экран
├── Dialogues/             # Диалоги игры
├── fonts/                 # Шрифты
├── *.gd                   # Скрипты на GDScript
└── *.tscn                 # Сцены проекта
```

## 🎮 Основные компоненты

- **MainHero** - управляемый персонаж
- **CameraFollow** - система слежения камеры
- **Enemy One/Dog Husky/Dog Two** - враги
- **Lock One** - интерактивный объект/замок
- **Power Slash** - способность атаки
- **Global UI** - глобальный интерфейс
